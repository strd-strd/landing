## Аудит: маркетинг и доверие (2026-10-08)

**Вердикт:** оффер и связка с живым прокатом сильные; для холодного трафика доверие среднее — обещания цифр опережают доказательства.

| Критерий | Балл | Комментарий |
| --- | --- | --- |
| Ясность оффера | 7/10 | Пул от 100k + своё авто понятны |
| Доверие тёплого (знает парк) | 7–8/10 | demidovpark.ru, основатель, с 2016 |
| Доверие холодного (Директ / SEO) | 4–5/10 | Цифры без скринов выплат |
| Social proof под аудиторию | 3/10 | MyReviews = арендаторы, не инвесторы |
| Риск «развод»-ассоциаций | высокий | Пока нет кейсов выплат |

### Что уже работает

- Живой прокат рядом (парк ~100, с 2016, основатель-инвестор) — главный якорь.
- Низкий порог 100k + «условия на встрече» — честнее, чем «от миллиона».
- Калькуляторы + CTA с контекстом.
- Без фейковых ФИО в отзывах; ПДн, карта, юрлицо.

### Где ломается доверие

1. Hero «от 45 000 ₽/мес» + сутки/неделя — ближе к доходу проката, чем к доле инвестора; для холодного трафика звучит как реклама пассива.
2. Не тот social proof: арендаторы ≠ инвесторы.
3. «~25% годовых» без доказательств усиливает скепсис.
4. Формы без реального бэка — один «тишина после заявки» бьёт по репутации.
5. Два продукта сразу (пул / своё авто) чуть размывают первый экран.
